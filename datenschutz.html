Hinweis für gemeinsam genutzte Geräte: Andere Personen mit Zugang zum selben Browser können die gespeicherten Angaben sehen. Bitte geben Sie keine Namen oder andere persönliche Angaben in Antwort- oder Notizfelder ein. Sie können die Daten jederzeit löschen, indem Sie die Website-Daten in Ihrem Browser löschen.

Einige Übungen bieten eine Vorlesefunktion. Sie nutzt die Sprachausgabe Ihres Browsers bzw. Betriebssystems und wird nur gestartet, wenn Sie selbst auf eine Vorlese-Schaltfläche tippen. Die Website selbst überträgt dabei keine Daten. Je nach Browser und ausgewählter Stimme kann die Sprachausgabe jedoch über einen Online-Dienst des Browser- oder Betriebssystem-Herstellers (z. B. Google, Apple oder Microsoft) erfolgen. In diesem Fall erhält dieser Hersteller den vorzulesenden Text und technische Verbindungsdaten wie Ihre IP-Adresse. Dies geschieht in der Verantwortung des jeweiligen Herstellers und nach dessen Datenschutzbestimmungen. Wenn Sie das vermeiden möchten, wählen Sie eine auf dem Gerät installierte Stimme oder verzichten Sie auf die Vorlesefunktion. Die Lehrer-Aufnahmen in den Lesemissionen werden dagegen direkt von GitHub Pages geladen.
