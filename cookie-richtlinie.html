1. Das Wichtigste in Kürze

  • Die Website setzt keine Cookies.
  • Es gibt keine Tracker von Drittanbietern, keine Analyse- und keine Werbedienste.
  • Für die Lernfunktionen nutzt die Website den Speicher Ihres Browsers (z. B. Local Storage und Session Storage). Diese Angaben bleiben auf Ihrem Gerät und werden nicht übertragen.
  • Da nur unbedingt erforderliche Speicherungen stattfinden, ist keine Einwilligung nötig. Deshalb gibt es keinen Cookie-Banner.

3. Cookies

Cookies sind kleine Textdateien, die eine Website im Browser ablegt und die bei jedem weiteren Abruf an den Server zurückgesendet werden. Diese Website setzt keine Cookies. Auch der Hosting-Anbieter GitHub Pages setzt beim Abruf dieser Website keine Cookies.

4. Speicherung im Browser

Damit Sie später weiterüben können, legt die Website Informationen im Speicher Ihres Browsers ab. Anders als Cookies werden diese Informationen nicht an einen Server gesendet. Sie verbleiben auf Ihrem Gerät. Weder wir noch Dritte können sie einsehen. Alle Einträge stammen von dieser Website selbst (sogenannte First-Party-Speicherung).

Übungsstände werden je Lernplatz gespeichert. Die Lernplätze sind nummeriert und enthalten keine Namen.

Local Storage

Im Local Storage speichert die Website zum Beispiel Übungsstände und Sterne, eigene Antworten, Entwürfe und Notizen, das Aussehen des Lern-Avatars und die Avatar-Welt, Vorlese-Einstellungen sowie den ausgewählten Lernplatz.

Speicherdauer: unbegrenzt, bis Sie die Website-Daten in Ihrem Browser löschen oder der Browser sie entfernt.

Session Storage

Im Session Storage speichert die Website Angaben, die nur für die laufende Browser-Sitzung benötigt werden, zum Beispiel dass Sie den Datenschutz-Hinweis bestätigt haben.

Speicherdauer: bis zum Ende der Browser-Sitzung (in der Regel bis zum Schließen des Browsers).

5. Rechtsgrundlage und Einwilligung

Das Speichern und Auslesen von Informationen auf Ihrem Gerät ist nach § 25 Abs. 2 Nr. 2 Telekommunikation-Digitale-Dienste-Datenschutz-Gesetz (TDDDG) ohne Einwilligung zulässig, wenn es unbedingt erforderlich ist, damit ein von Ihnen ausdrücklich gewünschter Dienst bereitgestellt werden kann. Das ist hier der Fall: Ohne diese Speicherung könnte die Website Ihren Übungsstand, Ihre Einstellungen und Ihren Avatar nicht bereithalten.

Die gespeicherten Angaben werden nicht an uns übermittelt. Wir verarbeiten sie daher nicht. Weitere Informationen zur Datenverarbeitung finden Sie in der Datenschutzerklärung.

6. Einsehen und Löschen

Über die Einstellungen Ihres Browsers können Sie

  • einsehen, welche Daten diese Website auf Ihrem Gerät gespeichert hat,
  • diese Daten löschen und
  • das Speichern von Website-Daten generell blockieren.

Die Speicherung im Browser wird in den Einstellungen meist zusammen mit Cookies unter „Website-Daten“ oder „Websitedaten“ verwaltet. Anleitungen der gängigen Browser:

  • Google Chrome
  • Mozilla Firefox
  • Apple Safari
  • Microsoft Edge

7. Folgen des Löschens oder Blockierens

Wenn Sie die Website-Daten löschen, gehen gespeicherte Übungsstände, Sterne, Antworten, Notizen und Avatar-Einstellungen auf diesem Gerät unwiderruflich verloren. Wir können sie nicht wiederherstellen, da wir keine Kopie besitzen. Wenn Sie das Speichern blockieren, können Sie weiterhin üben, Ihr Fortschritt wird dann aber nicht gespeichert.

8. Änderungen

Wir passen diese Cookie-Richtlinie an, wenn sich die Website ändert. Es gilt die jeweils auf dieser Seite veröffentlichte Fassung.
